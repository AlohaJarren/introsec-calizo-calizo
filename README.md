# Introduction to Security

This repository is an archive of my introductory security coursework at Portland State University. Most of the material is in PDF lab notebooks, along with a link to my final project screencast.

I kept it as a record of the foundation I built before moving into more focused work in web and cloud security and generative AI security. Unlike my other repositories, this one is mainly lab documentation rather than a standalone software application.
